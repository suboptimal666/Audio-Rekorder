Ein einfaches Windows-Tool, um den Systemton (z.B. von Webseiten oder Apps) aufzunehmen, zuzuschneiden und als fertige MP3-Datei zu speichern.

## ⚠️ WICHTIGE VORAUSSETZUNG
Damit das Programm den Ton aufnehmen kann, benötigst du das kostenlose Tool **VB-Cable**.
1. Lade es hier herunter und installiere es: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)
2. Starte deinen PC neu.
3. Stelle sicher, dass die Anwendung, deren Ton du aufnehmen möchtest, auf das Wiedergabegerät **"CABLE Input"** zugreift.

## 🚀 Installation & Start
1. Gehe auf dieser Seite in den Bereich **[Releases](https://github.com/suboptimal666/Audio-Rekorder/releases))**.
2. Lade die Datei **`Hoerspiel-Rekorder.exe`** herunter.
3. Mache einen Doppelklick auf die Datei. Es ist keine Installation von Python oder anderen Programmen notwendig!

## 📖 Bedienung
1. **Titel:** Trage den gewünschten Namen für die Datei ein.
2. **Länge:** Trage die geplante Aufnahmedauer in Minuten ein (z.B. 60).
3. **Aufnahme starten:** Klicke auf den grünen Button.
4. **Wiedergabe:** Starte nun die Wiedergabe in deiner Anwendung. Das Programm beginnt automatisch mit der Aufnahme.
5. **Zuschneiden:** Wenn die Zeit um ist, stoppt das Programm automatisch. Wähle die aufgenommene Datei in der Liste aus und klicke auf "Zuschneiden". Die fertige MP3 wird automatisch bereinigt und im gewählten Ordner gespeichert.

# 🎧 Audio Recorder & Cropper

A simple Windows tool to record system audio (e.g., from websites or apps), crop it, and save it as a finished MP3 file.

## ⚠️ IMPORTANT REQUIREMENT
To capture the audio, you need the free tool **VB-Cable**.
1. Download and install it here: [VB-Audio Virtual Cable](https://vb-audio.com/Cable/)
2. Restart your PC.
3. Make sure the application whose audio you want to record is playing to the device **"CABLE Input"**.

## 🚀 Installation & Start
1. Go to the **[Releases](https://github.com/suboptimal666/Audio-Rekorder/releases))** section on this page.
2. Download the file **`Hoerspiel-Rekorder.exe`**.
3. Double-click the file to start. No installation of Python or other software is required!

## 📖 How to use
1. **Title:** Enter the desired name for the file.
2. **Length:** Enter the planned recording duration in minutes (e.g., 60).
3. **Start Recording:** Click the green button.
4. **Playback:** Now start the playback in your application. The program will start recording automatically.
5. **Crop:** When the time is up, the program stops automatically. Select the recorded file in the list and click "Crop File". The final MP3 is automatically cleaned and saved in the selected folder.
